# Prompt — Spec

Input:  roadmap.md, constitution.md, AGENTS.md, current codebase, target phase.
Output: docs/sdd/features/<id>/spec.md

Write acceptance criteria as Given/When/Then, numbered AC-1..n, each testable.
Trace back to goals and to the phase/feature id. List blocking open questions
under `## Open questions`.

Do not design. Do not name files. Do not resolve open questions — that is Clarify.
