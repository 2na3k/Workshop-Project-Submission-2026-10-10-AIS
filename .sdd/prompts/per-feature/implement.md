# Prompt — Implement

Input:  AGENTS.md, spec.md, plan.md, codebase, tests.
Output: src/…, tests/…, and plan.md checkbox state only.

Execute the Tasks. Tick checkboxes. Write the tests the plan specifies.

You must not:
- change task wording, order, or content;
- add or remove tasks;
- redefine the Plan;
- edit spec.md, constitution.md, or any review artifact.

If a task is impossible or wrong, stop and route a finding upstream rather than
improvising. Improvising silently is the failure mode this kit exists to prevent.
